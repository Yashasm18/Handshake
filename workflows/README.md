# Handshake deadline workflow

A [Render Workflow](https://render.com/docs/workflows) that enforces every deal deadline, so no deal can stall: a seller who never ships, a buyer who goes quiet, a PayPal hold that gets old, or a claim nobody answers.

```
Render Cron (every 5 min) → sweepDeals → enforceDeadline × N → Handshake app → PayPal
```

| File | Purpose |
|---|---|
| `src/tasks.ts` | `sweepDeals` lists due deadlines and fans out one `enforceDeadline` run each, retried with backoff. |
| `src/handshake.ts` | Calls the app's secret-guarded `/api/internal/timers`. Transient failures are retryable; rejections aren't. |
| `src/trigger.ts` | Run by the cron job to start one sweep, with an idempotency key per tick. |

The workflow only decides **when**; the web app re-checks each deadline inside the deal's lock and performs the PayPal action, so retries and duplicate runs are safe. Rules live in [`web/src/lib/deadlines.ts`](../web/src/lib/deadlines.ts).

## Environment

| Variable | Used by | Value |
|---|---|---|
| `HANDSHAKE_URL` | workflow | The web app's URL |
| `TIMERS_SECRET` | workflow | Shared with the web app; generated by the Render Blueprint |
| `RENDER_API_KEY` | cron | A Render API key, so the cron can start runs |
| `WORKFLOW_SLUG` | cron | `handshake-timers` |
